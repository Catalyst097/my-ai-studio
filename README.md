# AI, Data & DSA Interactive Learning Suite

A 100% browser-based interactive learning suite with 4 studios:

1. **ML Math & Pipeline Studio** (`ml_studio.html`) — Bell Curve & Z-Scores, Bayes' Theorem, Gradient Descent, Dot Product, Linear Regression, Precision/Recall, Quiz, and an interactive `scikit-learn` Pipeline Builder.
2. **Pandas & MySQL Syntax Studio** (`pandas_sql_studio.html`) — Live Filter, GroupBy/Window, and Join Playgrounds (Self Join, Anti Join, Cross Join, Duplicate Key explosion), CTEs, `LAG`/`LEAD`, Regex, and 25 Syntax Recall Drills.
3. **DSA Interactive Debugger** (`algo_studio.html`) — 9 core interview patterns (Two Pointers, Sliding Window, Binary Search, Hash Map, Sorting, BFS/DFS Trees, Stack, Linked List, Dynamic Programming) + Spot-the-Pattern Interview Trainer.
4. **PyAlgoLab** (`py_algolab.html`) — Live editable Python 3.12 in the browser (powered by Pyodide + `sys.settrace`) rendered on 3D isometric tiles.
